# פתיחה — סביבת העבודה שלכם
**20 דקות בכיתה.** המטרה היא לדעת לערוך תא, להריץ קוד, להבין גרף ולשמור עבודה שאפשר להמשיך ממנה.

אפשר לעבוד בפרק הפתיחה של המחברת המרכזית, או במחברת הקצרה:

[פתיחה ב־Colab](https://colab.research.google.com/github/yaminbens/alpha-mentorship/blob/main/notebooks/00_getting_started.ipynb)
[הורדת המחברת](../../notebooks/00_getting_started.ipynb)

1. פתחו ב־Colab ובחרו **File → Save a copy in Drive**. תנו שם הכולל את קוד התלמיד שסוכם עם המנחה.
2. הריצו את התא הראשון. בתא הגרף מופיעים ערכים מומצאים לצורך היכרות עם הכלי.
3. שנו את `scale` מ־1 ל־2. הריצו מחדש את תא המשתנה ואז את תא הגרף.
4. הוסיפו שורת `print` שמדפיסה את `scale` וכתבו משפט על השינוי בגרף.
5. שמרו, סגרו ופתחו שוב את העותק האישי. בדקו שהקוד, התשובה והגרף נשארו.

**אם המחברת אינה נפתחת:** הורידו אותה מהקישור למעלה, פתחו [Colab](https://colab.research.google.com/) ובחרו **File → Upload notebook**. בחרו בקובץ `.ipynb` שהורדתם ושמרו עותק ב־Drive.

**סיימתם כאשר:** אתם יכולים להראות שינוי בקוד, את ההשפעה שלו בגרף, ועותק שמור. שלחו קישור בדיקה למנחה לפי [הוראות השמירה](submit.md).
