# English–Hebrew glossary
| English | עברית | Meaning in this course |
|---|---|---|
| Model | מודל | Rules and assumptions representing part of a physical system |
| Force | כוח | Interaction that changes motion |
| Energy | אנרגיה | Kinetic plus potential contributions; report reduced units |
| Temperature | טמפרטורה | Kinetic measure here, not necessarily a fixed input |
| Phase | פאזה / מצב צבירה | Bulk behaviour; classroom visual labels are provisional |
| Density | צפיפות | Particle number divided by area in our 2D model |
| Configuration | תצורה | Positions at one time |
| Trajectory | מסלול בזמן | Sequence of positions and other quantities |
| Probability | הסתברות | A property of a specified sampling law |
| Entropy | אנטרופיה | Uncertainty for a specified distribution and variable |
| Mutual information | מידע הדדי | Dependence comparing joint and product laws |
| Control variable | משתנה מבוקר | A quantity kept fixed in the comparison |
| Uncertainty | אי־ודאות | Limits on what measurements determine |
| Neighbour | שכן | A particle selected by an explicit distance/rank rule |
| Notebook | מחברת חישובית | Text, executable code and saved outputs |
| Reduced units | יחידות מצומצמות | Units set by model scales, not automatically SI |
