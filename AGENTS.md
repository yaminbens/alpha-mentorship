# Alpha teaching repository
Keep this repository independent of GNN. Use relative paths and small CPU examples.
Read README.md and STATUS.md before changing scope. The first meeting is 60 minutes;
only the mentor demonstrates a simulation in class. Students perform the experiment
at home and save answers in Colab. Preserve explanations, equations and limitations.
Define terms before using them. Separate synthetic examples, measured observations,
hypotheses and validated results. A screenshot does not determine mutual information.
Do not publish student records. Mentor guides here contain no personal information;
answer keys in a public repository are visible even if excluded from the website.
Run `python tools/build_site.py` and `python -m pytest tests -q` after relevant edits.
For notebooks run `python tools/check_notebooks.py`. Save evidence under validation/.
Do not label a local notebook test as a live Google Colab/account-sharing test.
