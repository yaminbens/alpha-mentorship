# Editing and checking
Edit student text under site/pages/ and the associated assignment or reading source.
The build copies only explicitly selected material into dist/. It never publishes mentor/.
Use real repository paths in site/pages/ Markdown links (for example task-0.md,
not task-0.html). The builder maps these to published HTML/download paths.
Keep each פתיחה ב־Colab link followed by its הורדת המחברת link; the builder
turns that pair into the site's launch buttons. Both links also work on GitHub.
Notebook sources are generated by tools/make_notebooks.py; edit that source, regenerate,
and execute the notebooks. Example data are labelled and generated reproducibly.

```sh
python -m pip install -r requirements.txt
python tools/make_notebooks.py
python tools/build_site.py
python -m pytest tests -q
python tools/check_notebooks.py
python -m http.server 8000 --directory dist
```

Use `python tools/build_slides.py` to rebuild the twelve-slide Hebrew presentation
(standalone HTML and PDF) and facilitator guide (HTML/PDF). Six research slides
remain a ten-minute talk; three support classroom activities and three form a scientific appendix.
The embedded Noto Sans Hebrew font is vendored with its SIL Open Font License. This builder and
browser checks require Playwright, installed separately with `pip install playwright`
and `python -m playwright install chromium`. No student needs these build tools.
Keep source links, licenses, seeds, settings and units with copied or generated assets.
Commit source and useful small teaching outputs; ignore temporary runtimes and student work.

## Hebrew coding track
The student entry point is the Hebrew GitHub Pages book, built from site/pages/.
Keep its chapter navigation and per-activity Colab links. The combined workbook
notebooks/student_workbook_he.ipynb is optional. Keep repository documentation
in English; student-facing pages, notebooks and requested Hebrew teaching assets
remain in Hebrew. Edit the Hebrew
lessons in tools/make_notebooks.py and the independent-particle engine in
simulation/teaching_particles.py, then regenerate notebooks. The engine is embedded
verbatim so students need no repo checkout. Reading units live in readings/cards_he.json
and the free reflection in assignments/reflection_he.md. Keep the reading page aligned
with the units embedded in notebooks. Use flowing Hebrew explanations and purposeful
headings. The closing reflection concerns interests, difficulties and next directions;
it is not a graded report or a completion gate.

`tools/legacy_notebooks.py` preserves five optional scientific notebooks in English
and regenerates the original browser-track notebooks under archive/. It is imported
by the main generator. Do not silently replace their scientific model with the
independent-particle teaching model.

Run `python tools/check_student_paths.py` after changing learner code templates. It
checks completed learner paths in temporary copies, never inserting answers into
student files. `mentor/coding_reference.py` is public reference material and must
not be imported by student notebooks. Update the browser checker when adding pages.
