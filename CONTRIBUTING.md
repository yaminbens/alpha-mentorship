# Editing and checking
Edit student text under site/pages/ and the associated assignment or reading source.
The build copies only explicitly selected material into dist/. It never publishes mentor/.
Use real repository paths in site/pages/ Markdown links (for example task-0.md,
not task-0.html). The builder maps these to published HTML/download paths.
Keep each Open in Colab link followed by its Download notebook link; the builder
turns that pair into the site's launch buttons. Both links also work on GitHub.
Notebook sources are generated by tools/make_notebooks.py; edit that source, regenerate,
and execute the notebooks. Example data are labelled and generated reproducibly.

```sh
python -m pip install -r requirements.txt
python tools/make_notebooks.py
python tools/build_site.py
python -m pytest tests -q
python tools/check_notebooks.py
python -m http.server 8000 --directory dist
```

Use `python tools/build_slides.py` to rebuild the twelve-slide Hebrew presentation
(standalone HTML and PDF) and facilitator guide (HTML/PDF). Six research slides
remain a ten-minute talk; three support classroom activities and three form a scientific appendix.
The embedded Noto Sans Hebrew font is vendored with its SIL Open Font License. This builder and
browser checks require Playwright, installed separately with `pip install playwright`
and `python -m playwright install chromium`. No student needs these build tools.
Keep source links, licenses, seeds, settings and units with copied or generated assets.
Commit source and useful small teaching outputs; ignore temporary runtimes and student work.
