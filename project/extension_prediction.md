# Optional extension — predicting motion
For a future study define X as a local structural feature at time t and Y as whether
that particle retains a specified fraction of neighbours at t+lag. Specify the
particle/time sampling law and preparation conditions. Joint pairs use the same
particle/time; a product-law comparison draws donors independently from the same
population. Nearby times from one trajectory are not independent test runs.

Compare a simple threshold rule with a classifier using complete independent runs
for training and testing. Report class balance, a constant-prediction baseline and
held-out errors. Do not equate classification performance with MI, causality or
thermodynamic entropy. Notebook 05 illustrates the split on labelled synthetic data;
it is not evidence for this physical hypothesis. A real study needs a separate agreed
sampling plan and adequate trajectories.
