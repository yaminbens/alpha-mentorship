# הניסוי הראשון בבית — צעד אחר צעד
אפשר לענות בעברית או באנגלית. משפטים קצרים וברורים מספיקים. כתבו תחזית לפני
ההרצה, והשאירו אותה גם אם התוצאה שונה. אין צורך לכתוב קוד הדמיה.

## משימה 1: להתבונן ולתאר — כ־20–30 דקות
1. פתחו את מחברת משימה 1 ושמרו עותק אישי ב־Drive. החליפו את הנקודות בתשובות.
2. כתבו: ״כשנוסיף אנרגיה אני מצפה שהתנועה תהיה … והסידור יהיה … כי …״.
3. פתחו את ההדמיה, עצרו אותה, ובתפריט Data בחרו All atoms. הדביקו את כל קובץ
   ordered_initial.txt ולחצו Input state.
4. בדקו: 64 חלקיקים, צלע קופסה 12, כבידה 0 וצעד זמן 0.005.
5. הגדירו Steps per frame ל־200. לחצו Step חמש פעמים להכנה ועוד חמש פעמים
   להמתנה. שמרו צילום בשם task1_low.png. התקדמו עוד קצת ותארו את התנועה.
6. טענו מחדש את אותו קובץ מקורי. לחצו Step חמש פעמים, Faster בדיוק 24 פעמים
   בזמן שההדמיה עצורה, ואז Step עוד חמש פעמים. שמרו task1_high.png והתבוננו בתנועה.
7. מלאו במחברת: מה נשאר קבוע, מה השתנה בתנועה, מה השתנה בסידור, ומה עדיין לא ברור.

להגשה: תחזית, תנאים, שני צילומים, תיאור קצר ושאלה למנחה. במשימה הזאת אין צורך בגרף.

## משימה 2: למדוד ולהשוות — כ־60–90 דקות
אפשר לחלק לשני מפגשי עבודה. שמרו עותק אישי של מחברת משימה 2.
בצעו ארבע הרצות נפרדות: low עם 0 לחיצות Faster, middle עם 8, high עם 24,
ו־middle-repeat עם 8. בכל פעם מתחילים שוב מהקובץ המקורי.

בכל אחת מארבע ההרצות:

1. עצרו וטענו את הקובץ באמצעות Data, בחירת All atoms, ואז Input state.
2. הגדירו Steps per frame ל־200 ולחצו Step חמש פעמים.
3. לחצו Faster לפי מספר הלחיצות של ההרצה, בזמן שההדמיה עצורה.
4. לחצו Step עוד חמש פעמים להמתנה לפני המדידה.
5. לחצו Reset stats. ב־Data בחרו System totals וסמנו More detail. נקו את תיבת
   הנתונים הישנה. ודאו ש־Auto interval כבוי. אין לטעון מחדש את מצב החלקיקים עכשיו.
6. הגדירו Steps per frame ל־25. לחצו Step ואז Write data. חזרו על הזוג 40 פעמים.
7. העתיקו את כל הטבלה, כולל כותרות העמודות, לקובץ טקסט עם סיומת .tsv ושם ההרצה.
   שמרו צילום ותיאור קצר של התנועה והסידור.
8. במחברת, הדביקו את הטבלה בין שלושת המרכאות בתא חישוב הממוצעים. הריצו את התא.
   העתיקו את שני הממוצעים לשורה המתאימה בטבלת התוצאות, במקום None.

אחרי ארבע ההרצות הריצו את תא הטבלה ואת תא הגרף. כתבו כ־150 מילים בעזרת התבנית:
״שיניתי … ושמרתי … קבוע. ראיתי … והנתונים שתומכים בכך הם … . התחזית שלי
התאימה/לא התאימה כי … . עדיין לא ברור לי … ובשלב הבא הייתי מודד/ת …״.

הטמפרטורה נמדדת ביחידות המודל, לא בקלווין. מספר לחיצות Faster אינו טמפרטורה.
חזרה מאותו מצב התחלתי יכולה לתת בדיוק אותה תוצאה; היא בודקת את הביצוע ואינה
מעריכה אי־ודאות בין תנאי התחלה עצמאיים. גרף אנרגיה אינו מדידה ישירה של סדר,
והרצות קצרות אינן קובעות טמפרטורת התכה בשיווי משקל.

## בדיקה לפני הגשה
שמרו במחברת תחזית, שיטה, ארבע שורות תוצאות, גרף ומסקנה. שמרו בנפרד את ארבעת
קובצי הנתונים, הצילומים, הגרף וקובץ התוצאות. פתחו מחדש את המחברת, שתפו עם חשבון
המנחה שניתן בכיתה, ושלחו את הקישור בערוץ הפרטי שסוכם. שתפו גם את קובצי העזר.

אם נתקעתם: שמרו את העבודה החלקית וציינו באיזה שלב, מה ציפיתם ומה קרה. נתון חסר
נשאר ריק. אם השתמשתם בדוגמה שסופקה, סמנו זאת במפורש. האתר אינו שומר תשובות.
