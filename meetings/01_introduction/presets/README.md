# Saved browser states
ordered_initial.txt is the seeded triangular starting configuration (N=64, L=12,
gravity=0, dt=0.005). The *_observed files are final states from the low, middle,
high and replay preparations. They can be loaded through Data → Input state.
metadata.json specifies the source, exact interventions, windows, measured values
and limitations. Low/middle/high name energy preparations, not validated phases.
The high observation is disordered; the middle observation remains an intermediate
teaching comparison, not a separately established phase.
