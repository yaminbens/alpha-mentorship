# מסלול הדפדפן הקודם — ארכיון

המסלול הפעיל הוא [שלושת התרגילים בעברית](../../README.md). כאן נשמרו מחברות הפתיחה והתיעוד הקודמות כדי לא לאבד חומר לימודי. הקוד של מחברות אלה נוצר מחדש באמצעות `tools/legacy_notebooks.py`.

המחברות כאן אוספות תצפיות מסימולטור חיצוני; הן אינן המסלול האינטראקטיבי החדש. להוראות מודל הדפדפן השתמשו ב[מדריך הסימולציה](../../simulation/browser_guide.md) וב[מטלה המקורית](../../assignments/01_first_experiment/task.md).
