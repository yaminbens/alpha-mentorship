# Troubleshooting
| Symptom | Action |
|---|---|
| External simulator unavailable | Use the recorded fallback and supplied teaching data; label their source |
| Particles accelerate uncontrollably | Restore the saved initial state and appropriate time step; keep a note of the failed observation |
| No visible melting | Discuss faster vibration versus rearrangement; do not fabricate a phase label |
| Colab asks for login | Use the student's allowed account; otherwise download a notebook and use the approved submission channel |
| Notebook changes disappear | Open the student's Drive copy; save and reopen before proceeding |
| NameError after running a cell | Run setup cells in order, then restart and run all |
| Data file disappears | Restore from downloaded/Drive backup; runtime files are temporary |
| Mentor gets access denied | Share with the exact designated account and test the link |
| Plot cannot be interpreted | Check axes, units, example-versus-student data and preparation history |
| GitHub template opens read-only | Save a personal copy in Drive before editing |
| GitHub shows a notebook but there is no Run button | Follow Open in Colab at the top of the notebook or use the repository README table; GitHub provides a preview |
| Colab cannot fetch the GitHub notebook | Download the notebook from the student site, open Colab and use File → Upload notebook; then save a copy in Drive |

Use help from the program mentor for account restrictions; do not request student
passwords. Record reproducible software problems with the task and error, without
personal data or credentials.
